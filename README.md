# Radius Core - Telecom Testing & Validation

A modern React application for Radius Core, a telecommunications testing and validation company.

## Features

- **Hero Section**: Eye-catching landing page with gradient backgrounds and animated elements
- **Services Section**: Showcase of 6 core telecom testing services
- **Expertise Section**: Highlights key competencies and specializations
- **Call-to-Action**: Engaging contact section with modern design
- **Responsive Design**: Fully responsive layout for all device sizes
- **Modern Styling**: Built with Tailwind CSS for a sleek, professional appearance

## Tech Stack

- **React 18**: Latest React version for building UI components
- **Tailwind CSS**: Utility-first CSS framework for styling
- **PostCSS**: CSS processing with autoprefixer support

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

The app will open at `http://localhost:3000`

### Building for Production

```bash
npm run build
```

This creates an optimized production build in the `build` folder.

- **QA Automation**: CI/CD testing pipelines
